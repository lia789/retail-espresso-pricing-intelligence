# Espresso Coffee Shop Source Investigation

## URL Structure

```text
# Base URL
https://www.espressocoffeeshop.com/en/3-espresso-machines

# Product Page Example
https://www.espressocoffeeshop.com/en/semi-automatic-espresso-machines/1580-99725-ascaso-steel-duo-pid-macchina-espresso.htm
```

## Data Fields

```text
product_id      -> extracted from product URL
product_name
price

availability
product_url

```

Product identifier example:

```text

.../1580-99725-ascaso-steel-duo-pid-macchina-espresso.htm

```

## Scraping Investigation

```text
Static website with pagination.

Required product data is available from collection pages.
Individual product pages are not required for v1.
Brand is not available from the product cards, so brand will be null.
```

## XPath Code

```python
products = response.xpath(
    "//article[contains(@class, 'product-miniature')]"
)

results = []

for product in products:
    product_name = product.xpath(
        "normalize-space(.//a[contains(@class, 'product-miniature__title')])"
    ).get()

    product_url = product.xpath(
        "normalize-space(.//a[contains(@class, 'product-miniature__title')]/@href)"
    ).get()

    price = product.xpath(
        "normalize-space(.//span[contains(@class, 'product-miniature__price')])"
    ).get()

    out_of_stock = product.xpath(
        ".//li[contains(@class, 'out_of_stock')]"
    ).get()

    availability = "Out of Stock" if out_of_stock else "In Stock"

    results.append({
        "product_name": product_name,
        "product_url": product_url,
        "price": price,
        "availability": availability,
    })


next_page = response.xpath(
    "normalize-space("
    "//nav[@aria-label='Products pagination']"
    "//button[@aria-label='Go to next page']/@data-ps-data"
    ")"
).get()
```

import re

match = re.search(r"/(\d+)-\d+-", product_url)

product_id = match.group(1) if match else None
identifier = (
    f"espressocoffeeshop:{product_id}"
    if product_id
