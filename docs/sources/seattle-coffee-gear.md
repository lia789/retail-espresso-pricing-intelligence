## Scraping Investigation

```text
JavaScript driven website.

Use Python Playwright.

The collection page is used only for discovering product URLs and product names.

Individual product pages are visited because they contain more reliable product data, including product ID, brand, price, original price, and availability.

No pagination required for the current sale collection.
```

## XPATH Code

### Collection Page

```python
product_url = selector.xpath(
    "normalize-space((//a[starts-with(@href, '/products/')][.//h3])[1]/@href)"
).get()

title = selector.xpath(
    "normalize-space((//a[starts-with(@href, '/products/')][.//h3])[1]//h3)"
).get()
```

### Product Page

```python
product_id = selector.xpath(
    "normalize-space(//form[@id='product_form']/@data-productid)"
).get()

brand = selector.xpath(
    "normalize-space((//form[@id='product_form']//nav[@aria-label='breadcrumbs']/a)[last()])"
).get()

price = selector.xpath(
    "normalize-space((//form[@id='product_form']//span[@id='product_price-default'])[1])"
).get()

original_price = selector.xpath(
    "normalize-space((//form[@id='product_form']//span[@id='product_price-compare-at']//s)[1])"
).get()

is_available = selector.xpath(
    "//form[@id='product_form']//button[@id='product__add-to-cart' and contains(@class, 'ud-show')]"
).get()

availability = "In Stock" if is_available else "Out of Stock"
```
